# 🍃 Tea Company Website

A modern, responsive, and production-ready Tea Company Website built using the MERN Stack. This project is designed for a real tea business to showcase its products, company information, manufacturing process, gallery, and contact details.

## 📌 Project Information

**Project Name:** Tea Company Website

**Version:** 1.0

**Status:** In Development

# 🚀 Tech Stack

## Frontend

- React.js
- Vite
- Tailwind CSS
- React Router
- Framer Motion
- React Icons
- Swiper.js

## Backend

- Node.js
- Express.js
- MongoDB
- Mongoose

- Vercel (Frontend)
- Hostinger VPS / Render (Backend)
